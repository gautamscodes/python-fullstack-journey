# Tuple in Python

## Tuple

- It is sequence of items as a collection.
- It can also store multiple data type in its.
- Tuple not have adding and deleting function or methods.
- Once we stored the value inside the tuple then we can not update or modify the value again.
- it is faster than the list. 
- parenthesis is optional to create a tuple we can create tuple using comma, --> t1 = 1,2,3 this is also a tuple.
