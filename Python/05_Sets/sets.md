# Sets in Python

## Set

- Sets are non-sequential collection of items
- comma separated elements enclosed within {}
- sets not supports indexing.
- Slicing is also not allowed in set.
- set have uniqueness features in the sets.
- sets do not allow duplicate elements
- Concatenation is not supported in set.
- Python supports mathematical sets.
- Also, Repetition is not allow in set.
- sets are mutable.
- remove will remove the value form the list if it is present. If not present then it will give the error.
- discard will also remove the value from the set but if not present in the set then it will not give the error.
