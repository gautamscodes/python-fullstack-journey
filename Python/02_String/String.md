# String in Python

## String

- It is Sequence of Characters. 
- String are immutable in nature. 
- Immutable means once we declare any string then we can not update and modify that string.
- When we're performing some operation on string then it will crete new string pool their it will modify and update it.

## Slicing in String

- Slicing is a Technique through which we can fetch and access the part of the collection of characters.
- Index will fetch particular character it means one character at a time.
- Slicing will access entire characters.
- Slicing have starting index, ending index, stepping.
- [0:5:2] --> it means start from 0 go till 4 each time take step of 2.
- 0 to 4 because it excluded.
- If we give ending index out range while slicing then it will not give any error.
- But in indexing if we give ending index out range then it will give the error.

## Escape sequences in String

- \n --> new line
- \t --> tab
- \\ --> backslash
- \' --> insert a single quote inside a single-quote string.
