# Loops in Python

## Loops

- If we want to repeat sequence of data then we use loop
- there are two type loops in python.
- for loop and while loops.
- It is an iterator based loop which steps through the items of a collection (list, tuple, sets, dict, str), and executes a block of code repeatedly for a number of times equal to the items/elements of that collection.

## Range

- range() it is a built-in function which is used to generates sequence of integers in given interval
- syntax:- range(start, stop, step)
- stop is not included.
- and range function is used with for loop.
- If you print the ascending order then we have to take step as +ve.
- If we want to print as Descending order then we have to take step as -ve.
- Syntax:- range(start, stop) => step = 1 by default
- Range will work only with stop only. so if we not giving the start value and step value then it will take by default 0 as start and 1 as step.
